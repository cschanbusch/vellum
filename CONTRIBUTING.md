# Contributing

Thanks for wanting to help. Bug reports, store-format findings (from `--diagnose` reports, which
contain no personal data) and pull requests are all welcome.

## Licensing of contributions

Vellum is offered under the GPL with a commercial licence available on request, and some of its
skins are source-available with redistribution by permission (see [LICENSING.md](LICENSING.md)).
For that to keep working, Charles Schanbusch needs to be able to license contributions on the same
terms as the rest of the project.

By opening a pull request, you confirm that:

1. you wrote the contribution, or otherwise have the right to submit it;
2. it is licensed under the licence of the folder it changes (see [LICENSING.md](LICENSING.md));
3. you also grant Charles Schanbusch a perpetual, worldwide, royalty-free, irrevocable licence to
   use, modify, sublicense and relicense the contribution, including under a commercial licence or
   the licence of a showcase skin. You keep the copyright in your contribution.

Add this line to the pull request description to confirm:

> I agree to the contribution terms in CONTRIBUTING.md.

## Before you open a pull request

- Run the tests (see [README.md](README.md#commands)).
- Record any design choice in [docs/decisions.md](docs/decisions.md).
- Skins: follow [docs/skin-authoring.md](docs/skin-authoring.md) and test in the dev harness.
